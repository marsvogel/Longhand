# Support

Need help with Longhand? Here is where to go:

- **Questions, bugs, and ideas** → open an [issue](https://github.com/marsvogel/Longhand/issues). Please check [existing issues](https://github.com/marsvogel/Longhand/issues?q=is%3Aissue) first.
- **A rewrite came out wrong** → use the [rewrite quality form](https://github.com/marsvogel/Longhand/issues/new?template=rewrite_quality.yml). It asks for the transcript and the agent, which is what makes a prompt problem reproducible.
- **First launch and the model download** → see the [README](README.md#first-launch).
- **Building from source** → see [CONTRIBUTING.md](CONTRIBUTING.md#setup).
- **Security vulnerabilities** → do not open a public issue; use [private reporting](https://github.com/marsvogel/Longhand/security/advisories/new) instead (see [SECURITY.md](SECURITY.md)).

Some things belong upstream rather than here:

- Bugs in the `claude` CLI → [anthropics/claude-code](https://github.com/anthropics/claude-code/issues)
- Recognition errors from Whisper → [ggml-org/whisper.cpp](https://github.com/ggml-org/whisper.cpp/issues)

Longhand is a single-maintainer hobby project, so responses are best-effort — but every issue is read.
